## 在开天辟地之前

我们的寝室校园网线路很乱，经过最少三次大改。我没有了解详细经过，只知道现在，虽然大部分是被联通套了个家宽的皮垄断了，但还是有一些或是遗留或是不知道哪来的直接接入的真·校园网。当然，也是联通，而且因为 NAT3 又套 NAT，网络环境会更差。

入学时，我们的校园网办理前提是，寝室四个人必须都办一张联通校园卡，之后再额外交钱。我们寝室讨论之后觉得完全没有必要。以我自己举例，广电网销卡配合结转可以让我在一学期的四个月中每个月都拥有超过 300GB 的流量，而他们的也完全够用。

直到大二上。

## 盘古诞生记

大一到大二的暑假中，寝室校园网进行了“大升级”，为所有寝室安装了联通无线光猫，校园网账号直接和校园卡挂钩。29 元百兆 39 元两百兆。

我的某位舍友在此时成为了一位校园卡分销商，我使用他的账号进行测试之后，发现了一些有趣的事情。这些事情不一定都是在那时候发现的，其中也包含一些之后才知道的内容。

- 登录页面通过 DNS 劫持和 HTTP MITM 进行跳转，非常普通。在登录前只有运营商 DNS 和登录页面的 IP 可以访问，登录后无法通过跳转进入登录或登出页面。如果在登录之后关闭了登出页面而又无法输入网址，则此次登录会话只能通过另一部设备在进入登录页面后通过设备管理登出。
- 每个设备都可以获得一个由 DHCP 分配的公网 IPv4 地址，子网掩码为 /19。无防火墙，无 IPv6 地址，但有 IPv6-PD 广播，可以通过支持的设备获得子网掩码为 /60 的 IPv6 网段。
- 设备上限为 1，一年后静默修改为 2。
- IP 和路由对第三方来说与普通的联通家宽相同，带宽也相同（下载 100Mbps 上传 40Mbps）。
- 没有 NAT 设备检测。
- 在 DHCP 租约过期之后，IP 地址会变化，而 MAC 地址不会变。由于草台班子，此时 MAC 地址被视作已登录，而 IP 地址被视作未登录。这会导致客户端无法访问互联网，同时也无法进入登录页面，必须重启客户端网络接口。

于是我从某位群友那里付邮送拿到了一台已经刷入 OpenWRT 的斐讯 N2，下游设备连上并登录后，路由器即可用来为整个寝室提供网络。

过了一段时间，我们发现通过这种方式接入网络会共享带宽，而只有百兆的带宽上限导致这种影响十分严重。
