## 什么是 QCN

QCN 是高通机型存放手机 IMEI、MEID 和其它网络校准值数据的文件，它位于手机 EFS 分区内。如果因为某些意外操作导致 QCN 数据损坏，可能会因为丢失手机 IMEI 而不能识别 SIM 卡，出现手机无信号，不能上网和打电话等问题。

这时如果有 QCN 备份文件，则可以通过恢复备份解决。甚至手机 NV 数据已损坏问题，也可能通过恢复 QCN 解决。

要查询手机是否丢失 IMEI，可以在拨号界面输入 `*#06#` 查看。

## 准备工作

要备份或恢复手机 QCN，需要找一台 Windows 电脑配合操作。

电脑下载安装 [QPST 工具](/assets/QPST_2.7.496.zip)，安装过程可能会提示安装 Visual C++，一路下一步即可。

手机开启 Diagnostics 模式连接到电脑，开启方法有两个。

#### 拨号界面开启 Diagnostics 模式

在拨号界面输入 `*#*#717717#*#*`` 开启（该指令仅适用小米手机），输入后提示 Open diag enable 表示开启成功，重新输入一遍即关闭。

如果提示 Open diag failed 表示开启失败，通常新机型会这样，只能用第二种方法开启。

#### ADB 命令开启 Diagnostics 模式

这要求手机已获取 Root 权限，并开启 USB 调试连接电脑，分别运行下面命令（前两个命令运行后留意手机上的授权提示）。

```sh
adb shell
su
setprop sys.usb.config diag,adb
```

要确认手机是否以 Diagnostics 模式连接电脑，打开电脑设备管理器，查看“端口（COM 和 LPT）”下面是否显示有设备连接。

![设备管理器显示设备连接](/img/备份%20QCN/device-diag-connection.png)

## 备份手机 QCN

打开 QFIL 工具（在电脑开始菜单 QPST 文件夹下），点击“SelectPort”按钮，选中设备连接端口，点击“OK”确认。

![QFIL 选择设备连接端口](/img/备份%20QCN/qfil-select-port.png)

点击菜单栏 Tools 下面的 QCN Backup Restore 选项。

![QFIL 菜单栏点击 QCN Backup Restore](/img/备份%20QCN/qfil-qcn-backup-restore.png)

设置 QCN 备份文件路径，勾选“Enable Multi-SIM”选项，点击“Backup QCN”按钮开始备份。

![备份手机 QCN](/img/备份%20QCN/qfil-backup-qcn.png)

如果备份提示 `Backup QCN Fail: Backup QCN Fail Check Connection Fail` 错误，可能是该机型不支持备份。原笔者测试了两台手机，同样方法和操作环境下，其中一台较老机型备份成功，另一台新机怎么都备份失败，原因不详。备用方法可以通过[备份基带](/_posts/2023-11-13-备份手机字库等-存档.md)来备份（对于恢复串号，基带效果可能不如 QCN 备份）。

日后如果要恢复手机 QCN，用同样流程点击上图 `Restore QCN` 按钮即可。如果用他人分享的 QCN 备份文件，需要先用支持十六进制的编辑器修改 QCN 里的 MEID 和 IMEI（电脑可以用 Ultraedit，手机可以用 HexEditor 或 MT管理器）。如果刷了其他人串号，手机将不能解 BL 和存在其它副作用。具体修改方法请自行网上查找。
